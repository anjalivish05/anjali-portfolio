### Project Structure

### 1. MoveSmart — Smart Mobility & Urban Transportation
*A smart mobility platform designed to support urban transportation management through incident reporting, interactive mapping, and structured incident tracking.*

- **Role:** Full-Stack Developer (2024)
- **Tech Stack:** React, TypeScript, Java Spring Boot, PostgreSQL, Leaflet Maps, Tailwind CSS
- **Key Features:**
  - Real-time road hazard reporting with geotagged GPS coordinates and photographic documentation.
  - Interactive operations map with marker clustering and clearance stage tracking.
  - Unique incident tracking IDs for municipal coordination and citizen status checks.
- **Links:** [Live Demo](https://move-smart-five.vercel.app) · [GitHub Repository](https://github.com/anjalivish05)

---

### 2. Stealth Pay — Privacy-Focused Payments (ERC-5564)
*A blockchain privacy payment protocol implementing ERC-5564 stealth addresses to eliminate public address traceability on Ethereum.*

- **Role:** Web3 & Full-Stack Developer (2026)
- **Highlight:** Developed and submitted to **ETHGlobal Mumbai** (November 2026).
- **Tech Stack:** Web3, Blockchain, Smart Contracts, ERC-5564, React, TypeScript, Wagmi/Viem
- **Key Features:**
  - Dual-key stealth meta-address generation (Viewing Key & Spending Key).
  - Interactive visual cryptographic derivation stepper explaining ephemeral key ECDH shared secrets.
  - Client-side payment scanner and one-click fund sweeper to clean destination wallets.
- **Links:** [Live Demo](https://stealth-pay-team1.vercel.app) · [ETHGlobal Showcase](https://ethglobal.com/showcase/stealth-pay-xtdtj)

---

### 3. Royal Edge Enterprises — B2B Wholesale Catalogue & Enquiry Platform
*A commercial B2B manufacturing catalogue and inquiry platform designed for wholesale apparel interlining and backing materials.*

- **Role:** Full-Stack Developer — **Freelance Commercial Project** (2024)
- **Tech Stack:** React, TypeScript, Java Spring Boot, PostgreSQL, Tailwind CSS
- **Key Features:**
  - Searchable dynamic product catalog with specifications and tiered bulk quantity brackets.
  - Step-by-step RFQ (Request for Quotation) engine with automated parameter selection.
  - Administrative back-office portal for customer inquiry ingestion and order routing.
- **Links:** [Live Demo](https://royal-edge-enterprise-v2.vercel.app) · [GitHub Repository](https://github.com/anjalivish05)

---

### 4. LibraryEase — Public Library Management & Digital Services
*A modern public library platform connecting municipal catalog management with conversational AI book discovery.*

- **Role:** Full-Stack Developer (2024)
- **Tech Stack:** React, Python, FastAPI, PostgreSQL, Google Gemini AI, Leaflet, Tailwind CSS
- **Key Features:**
  - Multi-branch catalog search with real-time inventory tracking and physical shelf navigation.
  - Virtual librarian powered by Google Gemini AI for contextual and thematic book discovery.
  - Member borrowing dashboards with loan tracking and automated renewal requests.
- **Links:** [Live Demo](https://libraryease-frontend.vercel.app) · [GitHub Repository](https://github.com/anjalivish05/LibraryEase-Vintage-and-Digital-Library)
